# 🎰 刮刮樂紓壓遊戲

> **HCI 專題** — 透過刮刮樂的得失機制，以壓力體驗達到情緒宣洩與紓壓效果。

---

## 簡介

這是一款以**刮刮樂**為核心互動形式的瀏覽器遊戲，靈感來自 Steam 上的 Scritch Scratch 等票券類輕遊戲。  
玩家從初始 1000 籌碼出發，購買不同等級的刮刮樂，體驗從刮開到揭曉結果的張力與情緒起伏——  
這種「可控的壓力 + 即時回饋」，正是紓壓的核心設計理念。

---

## 功能特色

### 核心玩法
- **三種票券**：基本款（50）、進階款（150）、豪華款（500）
- **機率加權獎池**：每張票有 35–38% 機率**直接扣錢**，刻意製造壓力
- **刮刮互動**：Canvas `destination-out` 合成，支援滑鼠與觸控
- **55% 閾值自動揭曉**：刮超過一半自動顯示結果

### 視覺效果
- **金屬質感覆蓋層**：仿刮刮樂銀箔的漸層與紋理
- **光澤掃光動畫**：CSS 動畫呈現真實卡片光澤感
- **粒子爆炸系統**：大獎噴出彩色紙屑（110 顆），小獎灑金幣（50 顆）
- **畫面閃光效果**：中獎綠光、扣錢紅光、大獎金光
- **卡片震動**：扣錢時的 CSS shake 動畫強化負向回饋
- **浮動獎品符號**：結果層三個 emoji 輕微浮動動畫
- **進度條**：即時顯示刮除百分比，增加透明感

### 音效系統（Web Audio API，無需外部檔案）
| 事件 | 音效描述 |
|------|---------|
| 刮除中 | 帶通濾波白噪音，模擬紙張摩擦聲 |
| 購買 | 雙音節「叮咚」點擊音 |
| 揭曉 | 白噪音 + 正弦波混合的「唰」聲 |
| 小獎 | C-E-G-C 四音符上行琶音 |
| 大獎 | 七音符上行 + 和聲持續 |
| 扣錢 | 下行鋸齒波（哀傷音效） |
| 破產 | 頻率由 380Hz 降至 25Hz 的戲劇性墜落音 |

### HCI 數據面板
- **局數**、**中獎率**、**最高獎金**、**淨盈虧**即時顯示
- 所有數值在每局後動態更新，讓玩家感受到積累的結果

## 心理設計原理（HCI 視角）

| 設計元素 | 心理效果 |
|---------|---------|
| 刮除動作 | **操作感** 帶來主動控制感，減少被動感 |
| 55% 閾值自動揭曉 | 避免長時間拖延造成焦慮，流暢地轉向下一個循環 |
| 扣錢機制（35–38%） | 「損失厭惡」製造壓力，中獎時對比更顯強烈 |
| 粒子特效 + 音效 | **即時感官回饋** 強化情緒峰值（peak-end rule） |
| 破產重置 | 明確終點 + 重新開始，提供「放下」的心理出口 |
| 金屬光澤動畫 | 「隱藏感」維持刮開前的期待與懸念 |

## 技術架構

```
hci-scratch/
├── index.html      # 頁面結構
├── style.css       # 深色主題 UI + 動畫
├── game.js         # 遊戲邏輯
└── README.md       # 本文件
```

**使用技術：**
- HTML5 Canvas（刮除效果、粒子系統）
- Web Audio API（合成音效，零外部資源）
- CSS 動畫（光澤掃光、震動、滑入）
- 純 Vanilla JS，無任何框架依賴

## 快速開始

不需要任何安裝或伺服器，直接開啟即可：

```bash
git clone https://github.com/Chiway1229/hci-scratch.git
cd hci-scratch
open index.html      # macOS
start index.html     # Windows
xdg-open index.html  # Linux
```

或直接雙擊 `index.html` 在瀏覽器中開啟即可遊玩。

## 遊戲說明

1. 選擇票券等級並點擊「購買」
2. 用滑鼠（按住拖曳）或手指（觸控）刮除銀色覆蓋層
3. 刮超過 55% 自動揭曉，或點擊「⚡ 一鍵全刮」
4. 查看結果：大獎 🏆、中獎 ⭐、沒中 😐、扣錢 💸
5. 籌碼歸零即破產，遊戲重置
