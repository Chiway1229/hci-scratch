# 🎰 刮刮樂紓壓遊戲

> **HCI 專題** — 透過刮刮樂的得失機制，以壓力體驗達到情緒宣洩與紓壓效果。

---

## 簡介

這是一款以**刮刮樂**為核心互動形式的瀏覽器遊戲，靈感來自 Steam 上的 Scritch Scratch 等票券類輕遊戲。  
玩家從初始 1000 籌碼出發，購買不同等級的刮刮樂，體驗從刮開到揭曉結果的張力與情緒起伏——  
這種「可控的壓力 + 即時回饋」，正是紓壓的核心設計理念。

---

## 功能特色

### 核心玩法
- **三種票券**：基本款（50）、進階款（150）、豪華款（500）
- **機率加權獎池**：每張票有 35–38% 機率**直接扣錢**，刻意製造壓力
- **刮刮互動**：Canvas `destination-out` 合成，支援滑鼠與觸控
- **55% 閾值自動揭曉**：刮超過一半自動顯示結果

### 洗碗打工系統（紓壓回血機制）
- **🧽 點擊洗碗**：每次點擊獲得籌碼，破產時的安全網
- **籌碼即時飛出動畫**：點擊瞬間顯示 `+N` 浮動文字回饋
- **肥皂泡泡粒子**：每次洗碗噴出藍白色泡泡
- **不再強制重置**：破產時不會重置遊戲，改為引導玩家去洗碗

### Cookie Clicker 風格升級系統
- **8 種升級道具**，價格依購買次數呈 1.15× 指數成長
- **點擊倍率類**（強化每次洗碗）
  - 🧤 橡膠手套（+1）
  - 🧴 高效洗碗精（+4）
  - 💦 高壓水槍（+15）
  - 📜 洗碗大師證照（+80）
- **自動收入類**（被動每秒入帳）
  - 🍽️ 家用洗碗機（+2/秒）
  - 🤖 洗碗機器人（+12/秒）
  - 🧠 AI 廚房系統（+60/秒）
  - 🏪 連鎖餐廳（+350/秒）
- **可購買時邊框會亮綠**，視覺暗示玩家「你現在買得起這個了」

### 視覺效果
- **金屬質感覆蓋層**：仿刮刮樂銀箔的漸層與紋理
- **光澤掃光動畫**：CSS 動畫呈現真實卡片光澤感
- **粒子爆炸系統**：大獎噴出彩色紙屑（110 顆），小獎灑金幣（50 顆）
- **畫面閃光效果**：中獎綠光、扣錢紅光、大獎金光
- **卡片震動**：扣錢時的 CSS shake 動畫強化負向回饋
- **浮動獎品符號**：結果層三個 emoji 輕微浮動動畫
- **進度條**：即時顯示刮除百分比，增加透明感

### 音效系統（Web Audio API，無需外部檔案）
| 事件 | 音效描述 |
|------|---------|
| 刮除中 | 帶通濾波白噪音，模擬紙張摩擦聲 |
| 購買 | 雙音節「叮咚」點擊音 |
| 揭曉 | 白噪音 + 正弦波混合的「唰」聲 |
| 小獎 | C-E-G-C 四音符上行琶音 |
| 大獎 | 七音符上行 + 和聲持續 |
| 扣錢 | 下行鋸齒波（哀傷音效） |
| 破產 | 頻率由 380Hz 降至 25Hz 的戲劇性墜落音 |

### HCI 數據面板
- **局數**、**中獎率**、**最高獎金**、**淨盈虧**即時顯示
- 所有數值在每局後動態更新，讓玩家感受到積累的結果

## 心理設計原理（HCI 視角）

| 設計元素 | 心理效果 |
|---------|---------|
| 刮除動作 | **操作感** 帶來主動控制感，減少被動感 |
| 55% 閾值自動揭曉 | 避免長時間拖延造成焦慮，流暢地轉向下一個循環 |
| 扣錢機制（35–38%） | 「損失厭惡」製造壓力，中獎時對比更顯強烈 |
| 粒子特效 + 音效 | **即時感官回饋** 強化情緒峰值（peak-end rule） |
| 洗碗打工 | **掌控感回復**：壓力後永遠有「靠勞力翻身」的路 |
| Cookie Clicker 升級 | **進步可視化**：數字成長提供長期目標與成就感 |
| 自動收入 | **離開觀察**：放著也能賺，降低焦慮、增加放鬆感 |
| 金屬光澤動畫 | 「隱藏感」維持刮開前的期待與懸念 |

## 遊戲說明

### 刮刮樂玩法
1. 切到「🎰 刮刮樂」分頁
2. 選擇票券等級並點擊「購買」
3. 用滑鼠（按住拖曳）或手指（觸控）刮除銀色覆蓋層
4. 刮超過 55% 自動揭曉，或點擊「⚡ 一鍵全刮」
5. 查看結果：大獎 🏆、中獎 ⭐、沒中 😐、扣錢 💸

### 打工玩法
1. 切到「💼 打工」分頁
2. 點擊大大的 🧽 按鈕洗碗賺籌碼
3. 累積籌碼後購買升級：
   - **點擊類**：提升每次洗碗收入
   - **自動類**：每秒被動收入，放著就賺錢
4. 越買越貴（指數成長 1.15×），規劃投資順序很重要！

### 破產時
不會強制重置遊戲，會建議你去打工區洗碗賺錢。從 +1 開始一路升級，
也能再次累積到能買豪華刮刮樂的本錢——這就是這款遊戲的紓壓循環。
